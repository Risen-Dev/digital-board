Everything a team needs in one place

Every view reads the same tasks, so nothing has to be kept in sync by hand.

Kanban board

Drag and drop with mouse, touch or keyboard. Cards show a cover image, checklist progress, priority, labels and overdue dates at a glance. Bulk edit, archive, and a history of every change.

List, Calendar, Analytics

The same tasks as a table, on a month grid by due date, and as charts for workload and 14-day activity.

Canvas

Excalidraw sheets per project with live collaboration: you see other members' cursors and edits as they happen.

AI agent

"Move WEB-12 to In Review", "draw the onboarding flow". Use it from the board, the canvas, or @agent in chat and in a card's comments to ask about that card. Works with Anthropic, OpenAI, Gemini or any compatible API.

Chat & meetings

Workspace channel and DMs with attachments, recurring meetings with attendee reminders, and a notification bell for mentions and due dates.

GitHub sync

Cards move as branches and PRs progress. Create an issue or open a PR from a card; CI results land in the card's history.

Integrations

An inbound webhook, email-to-ticket, an iCal feed for your calendar app, and an outgoing webhook that Slack and Discord accept as is.

Templates & Trello import

Six project templates (Tech, Sales, Marketing, Support, Recruiting, General) and import from a Trello JSON or CSV export.

Roles & accounts

Multi-user with per-project admin, editor and viewer roles, scrypt-hashed passwords and presence. Works on phones.

Install

Requires Node 22+ and PostgreSQL 14+.

sudo -u postgres psql -c "CREATE ROLE board LOGIN PASSWORD 'choose-something';"
sudo -u postgres psql -c "CREATE DATABASE board OWNER board;"

git clone https://github.com/Risen-Dev/digital-board.git
cd digital-board
npm install
cp .env.example .env      # set DATABASE_URL
npm run build
npm start

Open http://localhost:3000 and choose Create a workspace. Tables create themselves on first use; there is no migration command. Full guide in the README.
